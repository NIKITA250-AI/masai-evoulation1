Client & Server Communication

The client requests data and the server responds with resources.

Example: Your browser (client) asks Google’s server for a search result.

Note: HTTP1.1 is the most common protocol.

The Journey of a Web Request

  1. User enters URL
  2. Browser looks up IP via DNS
  3. Client sends HTTP request
  4. Server processes request
  5. Response is sent back and rendered
